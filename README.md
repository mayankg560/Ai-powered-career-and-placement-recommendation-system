 AI-Powered Career Intelligence and Placement Recommendation System



The AI-Powered Career Intelligence and Placement Recommendation System is a machine-learning-based application designed to help students understand their placement readiness and identify suitable career paths based on their academic performance, skills, experience, and other relevant factors.

The system provides three major functionalities:

1. Placement Prediction
2. Career Recommendation
3. Skill Gap Analysis

The application is developed using Python, Scikit-learn, Pandas, and Streamlit.

---

 Objectives

The main objectives of this project are:

- Predict whether a student is likely to be placed.
- Estimate the student's placement probability.
- Determine the student's placement readiness level.
- Recommend suitable career roles based on their skills.
- Identify skills that the student already possesses.
- Identify missing skills required for a selected career role.
- Provide students with data-driven career insights.

---

 Features

### 1. Placement Prediction

The system uses a machine learning classification model to predict placement status.

The prediction is based on factors such as:

- Academic performance
- Internships
- Projects
- Certifications
- Technical skills
- Soft skills
- Aptitude
- Communication
- Work experience
- Leadership roles
- Extracurricular activities
- Backlogs

The system provides:

- Placement Status
- Placement Probability
- Placement Readiness
